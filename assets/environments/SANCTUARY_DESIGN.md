# Cat Sanctuary collection screen

Background: `assets/environments/sanctuary_cottage_v1.png`, generated using
the built-in image tool after approval of the sanctuary mockup.

Prompt: portrait premium fantasy game background, warm timber cat refuge at
night, golden lanterns, ivy, arched moonlit window with distant castle, open
center for UI, stone floor, purple side cushions, no characters or interface.

The runtime screen is one navy/gold panel including Back and the title,
real rescue totals and breed discovery count, nine consistent breed cards,
locked silhouettes, milestone progress and Continue. Cards use existing live
kitten actors and the generated purple cushion from the royal result atlas.
All counts come from the union of completed campaign levels and saved level
records; each completed level is counted once. No saved progress is reset.

Tests cover real collection totals, all unlocked breeds, locked/empty states,
EN/FA rendering, localized counts, three viewport ratios, integrated header,
and return navigation. All nine existing UI languages retain their controls.
